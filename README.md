# Thumblify 🎬✨

A modern TypeScript-based web application to generate, preview, and manage high-quality YouTube thumbnails with a clean, fast, and responsive user experience.

🌐 Live Demo: [https://thumblify-myeh.vercel.app/](https://thumblify-myeh.vercel.app/)

---

# 🚀 Features

* 🎨 Clean and modern UI
* ⚡ Fast performance with TypeScript
* 📱 Fully responsive design
* 🌙 Smooth user experience
* 🖼️ Thumbnail generation & preview
* ☁️ Vercel deployment
* 🔥 Optimized frontend architecture

---

# 🛠️ Tech Stack

* ⚛️ React + TypeScript
* 🎯 Tailwind CSS
* ⚡ Vite
* 🌐 Vercel

# 📂 Installation

Clone the repository:

```bash id="exkl0c"
git clone https://github.com/your-username/thumblify.git
```

Move into the project folder:

```bash id="7bnk5n"
cd thumblify
```

Install dependencies:

```bash id="wm9i7p"
npm install
```

Start the development server:

```bash id="vf7lxh"
npm run dev
```

---

# 🧩 Build for Production

```bash id="i99v3d"
npm run build
```

Preview production build:

```bash id="wy4dri"
npm run preview
```
